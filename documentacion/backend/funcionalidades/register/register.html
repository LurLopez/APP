Registro, inicio de sesión y verificación de correo — Backend

Registro con verificación por email (código de 6 dígitos), login con 403 si no verificas, recuperación de contraseña y sesión JWT en cookie httpOnly.

✓ Implementado y probado · actualizado 2026-08-14

Qué hace

Crea cuentas con email + contraseña (bcrypt), envía un código de 6 dígitos por correo para verificar la cuenta (SMTP real o consola en desarrollo), inicia sesión solo con cuentas verificadas (403 EMAIL_NOT_VERIFIED en caso contrario), permite recuperar la contraseña con otro código por correo y gestiona la sesión con un JWT en cookie httpOnly (7 días).

El código de verificación

  • 6 dígitos, guardado como hash SHA-256 (nunca en claro), válido 15 min y máx. 5 intentos (al agotarse se consume y hay que pedir otro).
  • Se envía por correo con nodemailer/SMTP; sin SMTP configurado se imprime por consola (desarrollo).
  • Reenviable con POST /resend-code.
  • MAIL_TO_OVERRIDE redirige los correos a una dirección fija (solo pruebas).

Flujo de recuperación de contraseña

  1. POST /forgot-password { email } → si existe la cuenta, se envía el código ("Restablece tu contraseña — Cifra"). Responde 200 también si no existe (no filtra cuentas).
  2. POST /reset-password { email, code, newPassword } → valida el código (mismo esquema), cambia el hash con bcrypt y marca el correo como verificado (demostró acceso al correo).
  3. El usuario vuelve al login con la contraseña nueva.

Seguridad aplicada

  • Contraseñas hasheadas con bcrypt (10 rondas), nunca en claro.
  • Cookie httpOnly + SameSite=Lax; secure solo en producción.
  • Errores 401 genéricos en login (no revela emails registrados) y forgot-password que no filtra cuentas.
  • Login bloqueado sin verificar (403 EMAIL_NOT_VERIFIED).
  • Secretos en .env (JWT_SECRET, SMTP_*), nunca versionados.

Qué incluye / excluye

Incluye: registro + verificación por correo + reenvío, login (con bloqueo de no verificados), recuperación de contraseña, logout, /me, errores JSON con code, prueba de envío (npm run test:email).

Excluye (pendiente): iniciar sesión con Google, 2FA, planes premium con límites (Fase 5).
