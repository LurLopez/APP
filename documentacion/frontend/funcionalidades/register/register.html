Registro e inicio de sesión — Frontend

Interfaz de autenticación de Cifra: modal de login/registro, chip de usuario y estados de sesión.

✓ Implementado y probado · 2026-08-12

Qué hace

Da al usuario la interfaz para crear una cuenta, iniciar sesión y cerrar sesión, conectada con la API real del backend. Al cargar la página, la sesión se restaura sola (GET /api/auth/me).

Cómo funciona

  • Botones "Iniciar sesión" y "Crear cuenta" en la barra superior: abren el modal con pestañas.
  • Modal: valida los datos (contraseñas iguales, mínimo 8), llama a la API y muestra los errores del servidor dentro del propio modal.
  • Estado de sesión reflejado en dos sitios: chip de usuario en la topbar (avatar con iniciales + email + salir) y tarjeta de cuenta en el sidebar (Invitado ↔ email + plan).
  • El modal se cierra con ×, click fuera o Escape; el botón de envío se desactiva durante la petición.

Qué incluye / excluye

Incluye: modal con pestañas, validación cliente, errores del servidor en pantalla, restauración de sesión, logout, diseño responsive (en móvil se ocultan los textos).

Excluye (pendiente): histórico real por usuario, zona de perfil, cambio de contraseña.

Pruebas

Flujo completo verificado contra la API real (registro 201, login 200, /me 200/401, logout 200) y comprobación visual de ambos estados en topbar y sidebar.

Bug corregido (2026-08-12): el modal no se cerraba tras iniciar sesión porque el CSS (display: grid/flex) anulaba el atributo hidden del HTML. Se añadió la regla global [hidden] { display: none !important; } en styles.css, que protege todos los elementos ocultables (incluido el dropzone de subida).
