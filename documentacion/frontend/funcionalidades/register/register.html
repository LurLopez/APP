Registro, inicio de sesión y verificación de correo — Frontend

Modal con registro en dos pasos (credenciales → código de verificación), login, recuperación de contraseña y estado de sesión en topbar/sidebar.

✓ Implementado y probado · actualizado 2026-08-14

Qué hace

El usuario crea su cuenta con email + contraseña y, en un segundo paso del mismo modal, introduce el código de 6 dígitos que recibe por correo para verificarla. Si intenta entrar sin verificar (403 EMAIL_NOT_VERIFIED) el modal salta solo al paso de verificación. Desde el login también puede recuperar la contraseña con otro código por correo. Todo integrado con auth.js y el estado de sesión (chip de usuario, tarjeta de cuenta, evento auth:change).

Cómo funciona

  1. Registro: validación cliente (contraseñas iguales y ≥ 8) → POST /register → 201 → pasa al paso de verificación (el código llega por correo o por consola sin SMTP).
  2. Verificación: POST /verify → 200 → sesión iniciada y modal cerrado; errores (código incorrecto, caducado) dentro del paso con "Reenviar código".
  3. Login: POST /login → 401 genérico o salto a verificación si 403 EMAIL_NOT_VERIFIED.
  4. Recuperación: enlace en login → pedir código → introducir código + nueva contraseña → al completar, toast y vuelta al login.
  5. Logout: POST /logout → estado invitado; se emite auth:change para recargar histórico, listas y cartera.
